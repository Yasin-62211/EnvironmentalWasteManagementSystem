# Environmental Waste Management System

A simple Java-based project designed to manage and organize waste-related information.

## Project Overview

The Environmental Waste Management System is a Java application that helps manage different types of waste and their related information. The project was created to practice Java programming while working on an environmental problem.

## Features

* Add and manage waste information
* Store waste details using Java classes
* Manage waste records
* Read and write data using file handling
* Simple and organized Java code structure

## Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* **File Handling**
* **IntelliJ IDEA**
* **Git & GitHub**

## Main Components

### Main.java

The main entry point of the application.

### Waste.java

Represents waste-related information using a Java class.

### WasteManager.java

Handles waste management operations.

### FileManager.java

Handles file-related operations for storing and managing data.
